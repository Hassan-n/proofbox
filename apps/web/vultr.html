Evaluation Invariants & Guardrails

Integrity & Ethical Design Safeguards

  • Fictional Demo Data: All sample institutions (Kingfisher Bank, Karoo Bay Metro, Community Benefits Agency) and identity credentials are 100% fictional test records.
  • Mandatory Honest Wording: "No issue found" is intentionally styled as informational blue (never green) with the explicit declaration: "No issue found does not mean safe."
  • Deterministic Code Supremacy: Financial totals and tariff step charges are verified exclusively by tested Python calculation engines; models never guess or hallucinate currency totals.
  • Citizen Safety First: Inspection sandboxes never execute untrusted scripts on user devices, nor do they submit passwords or credentials to inspected endpoints.
